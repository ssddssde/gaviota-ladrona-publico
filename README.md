# Gaviota Ladrona — archivos públicos

Archivos que el juego *Gaviota Ladrona* lee desde internet. Se sirven con GitHub Pages.

- `config/v1/remota.json` y `remota.json.sig`: configuración remota de la economía, firmada. Solo datos, nunca
  código. El juego descarta cualquier archivo con firma inválida.
- `privacidad/`: política de privacidad del juego (pendiente).

El código del juego vive en un repo privado. Nada de este repo es secreto: no subir claves privadas ni datos de
jugadores.
